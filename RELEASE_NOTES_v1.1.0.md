# TB Undernutrition Transcriptomics reproducibility update v1.1.0

Status: PREPARED UPDATE BUNDLE - NOT PUBLISHED.

## Scope
This successor update preserves the frozen v1.0.0 analysis/release as the provenance baseline and adds the revision-specific GC6 cross-assay gene-identity robustness analyses introduced during manuscript revision, together with manuscript-v28 authorship metadata.

## Added analyses
- Shared-gene four-module GC6 baseline sensitivity.
- Strict identity-overlap three-module GC6 sensitivity.
- Module-level gene-identity overlap audit.
- Secondary 12-month, month-6 landmark, and paired prediagnostic sensitivity results under each score definition.

## Provenance boundary
The prespecified four-module GC6 analysis remains primary. The added analyses are post hoc robustness checks and do not replace or alter the original v1.0.0 results. No primary source data are modified. The v28 authorship update changes release metadata only and does not alter analytical outputs.

## Key revision-specific results
- Current four-module month-0 baseline: adjusted OR/SD 0.711; P=0.02178.
- Shared-gene four-module month-0 baseline: adjusted OR/SD 0.713; P=0.02236.
- Strict-overlap three-module month-0 baseline: adjusted OR/SD 0.696; P=0.01445.
- Twelve-month, month-6, and paired prediagnostic analyses remain non-confirmatory under all score definitions.
