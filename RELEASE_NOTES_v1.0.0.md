# Release notes — v1.0.0

## Scope

Initial public reproducibility release for:

**Distinct immune-metabolic transcriptomic remodeling in severe undernutrition during latent tuberculosis infection fails to transport as a progression-risk program across independent cohorts**

## Included

- Canonical Phase A and Phase B analysis scripts
- Frozen seven-module severe-undernutrition programme
- Exact R-confirmed discovery, Reactome, active-TB convergence, GSE79362, and GC6 outputs
- Five high-resolution main figures
- Supplementary Methods and Tables S1-S6
- Supplementary Data S1 exact-output archive
- R session/environment and external-resource provenance
- SHA-256 release manifest

vendored in the release. Their exact locally used copies are fingerprinted in
`provenance/UPSTREAM_RESOURCE_MANIFEST.tsv`.
